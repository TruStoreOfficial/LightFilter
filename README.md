# LightFilter
LightFilter is a flagship content filtering and blocking system by Orbit Technology LLC. designed to make the internet safer. The LightFilter System and "SuperAgents" allows it to be a local (or cloud, which is opitional) based in one app or extention with minimal preformance loss and great filtering ability.

## Description
LightFilter, or L!, is Orbit Technology LLC.'s flagship filtering extension and app.  Blocks whatever is needed, whenever it appears! Using local (or cloud) AI to block NSFW and other unwanted content/sites/etc. LightFilter is privacy focused, just like its parent company Orbit Technology LLC. who made the privacy searching tool called Orbit.

### Privacy First
Orbit Technology LLC. is a privacy first brand, **by default** the following preformance analytics are disabled:
* Blocked Websites, Images, Links, Video Frames (Media Blocking Analytics)
* Blocked Tracker and Ads (Ad and Tracker Analytics)
* Websites stalled from loading due to possible unwanted behavor (Stalling Analytics)
* App Functionality Analytics (Functionality Analytics)

Note that these can be enabled to improve others' experience, including yourself, but know, if these are enabled, the data will be stored, but not sold.
